# 用户协议页（protocol）技术文档

## 1. 页面概述

用户协议页是一个**纯静态展示页面**，用于展示《易迁易平台用户注册协议》的完整文本内容。页面不涉及任何后端交互或复杂逻辑。

- **页面路径**：`pages/protocol/protocol`
- **涉及文件**：`protocol.js` / `protocol.wxml` / `protocol.wxss` / `protocol.json`

---

## 2. 数据状态

无自定义数据字段。JS 文件仅包含空实现的页面生命周期钩子，无实际业务逻辑。

---

## 3. 生命周期

所有生命周期函数（`onLoad`、`onReady`、`onShow`、`onHide`、`onUnload`、`onPullDownRefresh`、`onReachBottom`、`onShareAppMessage`）均为空实现，无任何逻辑。

---

## 4. 页面内容

WXML 中硬编码了《易迁易平台用户注册协议》的完整文本，共 11 个章节：

| 章节 | 主题 |
|------|------|
| 一 | 本协议适用范围 |
| 二 | 平台服务使用规范 |
| 三 | 术语及解释 |
| 四 | 注册须知 |
| 五 | 注册与认证 |
| 六 | 用户权利与义务 |
| 七 | 责任范围和责任限制 |
| 八 | 特别授权 |
| 九 | 知识产权权属 |
| 十 | 隐私政策 |
| 十一 | 协议及服务的中断、变更或终止 |

---

## 5. 页面路由

| 来源 | 目标 | 说明 |
|------|------|------|
| 登录页 | `/pages/protocol/protocol` | 点击用户协议链接进入 |

---

## 6. 注意事项

1. **纯静态页面**：协议文本直接硬编码在 WXML 中，修改协议需更新代码发版
2. **JS 为空壳**：所有生命周期方法均为空实现，页面无任何动态行为
3. **无分享配置**：`onShareAppMessage` 为空，默认使用小程序全局分享配置
