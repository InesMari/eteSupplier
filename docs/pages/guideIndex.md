# 引导首页（guideIndex）技术文档

## 1. 页面概述

引导首页是用户**未登录状态下**看到的着陆页。展示供应商功能预览（运输管理、司机管理、车辆管理、我的财富），引导用户点击登录。页面本身不承载业务逻辑，仅作为入口引导。

- **页面路径**：`pages/guideIndex/guideIndex`
- **涉及文件**：`guideIndex.js` / `guideIndex.wxml` / `guideIndex.wxss` / `guideIndex.json`

---

## 2. 数据状态

无自定义数据字段（`data: {}`）。

---

## 3. 生命周期

### 3.1 onLoad

```
onLoad() → wx.login()
```

页面加载时调用 `wx.login()` 获取临时 code，为后续登录做准备。注意：这里仅调用 `wx.login()`，不使用其返回的 code（仅触发微信登录态刷新）。

---

## 4. 核心方法

### 4.1 getPhoneNumber - 跳转登录

```
getPhoneNumber() → wx.reLaunch('/pages/login/login')
```

虽然方法名为 `getPhoneNumber`，但实际上直接跳转到登录页（不获取手机号）。使用 `reLaunch` 关闭所有页面后打开登录页。

---

## 5. UI 布局

```
┌─────────────────────────────┐
│       [Banner 图片]          │
├─────────────────────────────┤
│  ┌──────────┐ ┌──────────┐  │
│  │ 运输管理  │ │ 司机管理  │  │
│  └──────────┘ └──────────┘  │
│  ┌──────────┐ ┌──────────┐  │
│  │ 车辆管理  │ │ 我的财富  │  │
│  └──────────┘ └──────────┘  │
├─────────────────────────────┤
│     您当前尚未登录            │
│     [立即登录]               │
└─────────────────────────────┘
```

- 功能入口仅为展示（无 `bindtap` 事件绑定），不可点击
- 底部有登录按钮和全屏透明遮罩 `click_popup`，点击任意位置都触发 `getPhoneNumber`

---

## 6. 页面路由

| 来源 | 目标 | 说明 |
|------|------|------|
| preserve 页（未登录） | `reLaunch` 进入本页 | 登录态失效时 |
| 本页 → 点击登录 | `reLaunch /pages/login/login` | 跳转登录页 |

---

## 7. 注意事项

1. **静态展示页**：功能卡片无实际交互，仅用于向未登录用户展示产品功能
2. **全屏点击**：`.click_popup` 透明遮罩使整个页面可点击触发登录跳转
3. **wx.login**：onLoad 中调用是为了提前获取 code，但当前代码未保存 code 值
